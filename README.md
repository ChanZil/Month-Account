# דוחות סיכום מנות

פלטפורמה ליצירת דוח Excel חודשי של מנות שנרכשו עבור **סמינר פנינים** ו**סמינר כתר חיה**.
מבנה הדוח זהה לדוחות החודשיים הקיימים.

## שימוש
1. פותחים את `index.html` בדפדפן (Chrome / Edge). לא צריך התקנה או אינטרנט.
2. בוחרים חודש ושנה. אפשר להרחיב או לצמצם את **טווח התאריכים** (למשל 31.08 עד 02.10).
3. לכל תאריך מזינים **כמות סועדות** לכל מוסד. מחיר ברירת המחדל למנה הוא 19.95 ₪ (לפני מע"מ). אפשר לשנות מחיר בכל שורה, או לקבוע מחיר לכל החודש בבת אחת.
4. כדי להוסיף לאותו תאריך מנות במחיר אחר (למשל בשבת), לוחצים **+** בקצה השורה.
5. שבתות נחשבות אוטומטית ל"שבת וחג". כדי לסמן יום חג, לוחצים "סמן כחג" ליד היום.
6. אפשר להוסיף הערה לכל שורה.
7. לוחצים **"הורדת דוח Excel"**.

הנתונים נשמרים אוטומטית בדפדפן, לכל חודש בנפרד.

**בפלאפון** כל תאריך מוצג ככרטיס עם שדות גדולים. ימים ריקים מוצגים מקוצרים עד שמתחילים להקליד בהם, ובתחתית המסך יש כפתור "היום" (קפיצה לתאריך של היום) וכפתור להורדת הדוח.

## הדוח
- עמודות (מימין לשמאל): יום בשבוע, תאריך ביצוע, פנינים (כמות סועדות, מחיר למנה, סה"כ), כתר חיה (אותו מבנה), מחיר (סה"כ לשורה), הערות.
- כל ימי התקופה מופיעים, גם ימים ללא מנות. תאריך עם כמה שורות מוצג עם יום ותאריך ממוזגים.
- שורות הסיכום: סה"כ מנות, סה"כ לתשלום ימי חול, סה"כ לתשלום ימי שבת וחג, סה"כ לתשלום ללא מע"מ וסה"כ לתשלום כולל מע"מ (18%, ניתן לעדכון), לכל מוסד ובסך הכול.
- החישובים בקובץ הם נוסחאות Excel, כך שתיקון ידני בקובץ מעדכן את הסכומים.

## קבצים
- `index.html`, `style.css`, `app.js`: ממשק המשתמש.
- `mobile.css`: עיצוב לפלאפון. נטען רק במסכים צרים (עד 640px), כך שהעיצוב במחשב לא מושפע.
- `report.js`: חישובים ובניית קובץ ה-Excel.
- `vendor/exceljs.min.js`: ספריית [ExcelJS](https://github.com/exceljs/exceljs) (רישיון MIT).
- `fonts/`: הגופנים Heebo ו-Frank Ruhl Libre (רישיון SIL OFL), כלולים כדי שהעיצוב יישמר גם בלי אינטרנט.
