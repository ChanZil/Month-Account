# דוחות סיכום מנות

פלטפורמה ליצירת דוח Excel חודשי של מנות שנרכשו עבור **סמינר פנינים** ו**סמינר כתר חיה**.

## שימוש
1. פותחים את `index.html` בדפדפן (Chrome / Edge). לא צריך התקנה או אינטרנט.
2. בוחרים חודש ושנה.
3. לכל תאריך מזינים מספר מנות לכל מוסד. מחיר ברירת המחדל למנה הוא 19.95 ₪ וניתן לשנות אותו לכל יום, או לכל החודש בבת אחת.
4. אפשר להוסיף הערה לכל יום והערה כללית לדוח.
5. לוחצים **"הורדת דוח Excel"**.

הנתונים נשמרים אוטומטית בדפדפן, לכל חודש בנפרד.

## הדוח
- טבלה אחת (מימין לשמאל) הכוללת: תאריך, יום, ולכל מוסד מנות, מחיר למנה וסה"כ. בנוסף סה"כ ליום והערות.
- נכללים רק ימים שהוזנו בהם מנות או הערה.
- שורת סה"כ חודשי וטבלת סיכום לתשלום לכל מוסד ולשניהם: מספר מנות, סכום לפני מע"מ, מע"מ וסה"כ כולל מע"מ.
- המחירים כוללים מע"מ, והמע"מ מפורק מתוכם (שיעור המע"מ ניתן לעדכון במסך).
- החישובים בקובץ הם נוסחאות Excel, כך שתיקון ידני בקובץ מעדכן את הסכומים.

## קבצים
- `index.html`, `style.css`, `app.js`: ממשק המשתמש.
- `report.js`: חישובים ובניית קובץ ה-Excel.
- `vendor/exceljs.min.js`: ספריית [ExcelJS](https://github.com/exceljs/exceljs) (רישיון MIT).
